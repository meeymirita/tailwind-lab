## О чём

Tailwind CSS v4 с нуля на сервисе аналитики «Pulse»: маркетинговый лендинг, дашборд и страница настроек. Азбука утилит → тема через `@theme` → варианты и состояния → адаптив и container queries → тёмная тема, формы и переиспользование → продакшн. В отличие от CSS-лабы, разметку вы пишете сами. Почти в каждой сессии есть шаг «сломать → починить»: динамический класс, которого нет в сборке; свой CSS, перебивающий утилиты; `peer`, который «не видит» чекбокс; `dark:`, не реагирующий на переключатель; `@apply`, падающий с «unknown utility».

## Стек

Tailwind CSS 4.3, Vite + `@tailwindcss/vite`, чистый HTML и немного JS. Всё в Docker: dev на Vite, prod-образ на nginx.

## Формат

Методичка [`tailwind.html`](tailwind.html) — открывается в браузере, прогресс по чекбоксам сохраняется локально. У каждого шага: код → «зачем» → команда → ожидаемый результат → «проверь себя»; ответы — в `docs/tailwind-notes.md`.

## Что внутри (6 сессий, ~20 ч)

- **Сессия 1** (~3 ч) — стенд и азбука: Vite + Tailwind, шкалы, flex/grid, Preflight, конфликты классов
- **Сессия 2** (~3 ч) — тема: `@theme`, фирменная палитра, брейкпоинты, анимации
- **Сессия 3** (~3,5 ч) — варианты и состояния: `group`/`peer`, `has-*`, динамические классы
- **Сессия 4** (~3,5 ч) — адаптив и container queries: лендинг, app shell, карточки метрик, таблица
- **Сессия 5** (~3,5 ч) — тёмная тема, формы, `@layer components`, `@apply`, typography
- **Сессия 6** (~3 ч) — продакшн: сборка, `@source`, Prettier, доступность, nginx, таблица «CSS-лаба ↔ Tailwind-лаба»

Разделы 1–9 методички — теория, раздел 10 — шесть сессий заданий, разделы 11–14 — чек-лист, глоссарий, вопросы для собеседования, что дальше.
